# 家校反馈平台（Home–School Feedback Platform）

一个面向培训机构与中小学老师的家校沟通产品原型：把老师日常口头的反馈，变成**可量化、可追踪、可留存**的成长记录。

> 在线演示：把本仓库开启 GitHub Pages 后访问 `https://<你的用户名>.github.io/<仓库名>/`
> 演示数据均为虚构，不含真实学生信息。

## 在线演示包含两个端

| 入口 | 文件 | 说明 |
| --- | --- | --- |
| 老师端 / 管理端 | `teacher.html` | 录入反馈、量化评分、照片视频、成长总览 |
| 家长端 / 手机页面 | `parent.html` | 查看反馈、每周成长报告、一键打印 |

打开 `index.html` 可以看到项目首页和两个入口。

## 核心功能

**老师端**

- 学生管理：按年级、班级增删与查找
- 反馈录入：反馈类型、课程、来源、常用模板，500 字以内
- 成长量化：专注力、参与表达、作业质量、行为纪律、合作沟通、学习兴趣 6 个维度 1—5 分
- 素材留痕：反馈可附照片、短视频，家长端可直接查看
- 成长总览：按全部 / 年级 / 班级对比本期与上期，自动标出进步维度、退步维度与需关注学生
- 学生成长档案：近 8 周平均分走势、各维度进退步、每周总评、素材与反馈记录
- 每周总评：老师为每个孩子写星级评价、总体情况、亮点与下周关注

**家长端**

- 未读提醒、标记已读、回复老师
- 查看老师上传的照片与视频
- 本周报告：老师周总评 + 量化小结 + 各维度与上周对比 + 反馈明细
- 一键生成可打印 / 可另存为 PDF 的周成长报告

## 技术说明

- 纯前端单文件实现（HTML + CSS + 原生 JavaScript），无构建步骤、无外部依赖，双击即可运行
- 数据保存在浏览器本地：文字数据用 `localStorage`，照片视频用 `localStorage` / `IndexedDB`
- 老师端与家长端在同一浏览器、同一域名下自动同步数据
- 图表（趋势图、对比条）为原生 SVG / CSS 绘制，不依赖第三方图表库

## 本地使用

1. 打开 `index.html`
2. 进入「老师端演示」，录入一条带评分、带照片的反馈
3. 进入「家长端演示」，即可看到刚录入的反馈，并生成每周报告

## 产品定位与后续规划

- 目标用户：民办培训机构、托管班、艺术 / 英语培训的老师（家长反馈直接影响续费，老师也有减负需求）
- 当前形态：零成本作品版，用于作品集展示与真实用户试用，不做商业化采集真实学生信息
- 后续规划：接入云数据库与账号体系（老师 / 家长角色、家长绑定孩子、权限控制）、消息通知、AI 辅助生成周评、隐私合规设计（监护人同意、最小化收集、数据删除机制）
