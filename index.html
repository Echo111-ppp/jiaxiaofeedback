家校反馈平台

把老师每天“随口一说”的反馈，变成可量化、可追踪、可留存的成长记录。

老师端：量化评分 + 照片视频 + 全班进退步总览　|　家长端：每周成长报告 + 一键打印

老师端 / 管理端

录入反馈与成长总览

适合老师日常使用，也方便校长、教研或机构管理者查看整体情况。

  • 六个成长维度 1—5 分量化评价
  • 反馈可附照片、短视频
  • 全班 / 年级进退步总览与需关注名单
  • 学生成长档案与每周总评
打开老师端演示
家长端 / 手机页面

查看反馈与每周报告

家长打开就能看到孩子的在校表现，一键生成可打印的周报告。

  • 未读提醒、回执与回复老师
  • 老师上传的照片、视频直接查看
  • 本周总评 + 各维度与上周对比
  • 一键生成 / 打印本周报告
打开家长端演示

这个版本包含什么

成长量化专注力、参与表达、作业质量、行为纪律、合作沟通、学习兴趣六维评分。
进退步可视化按周或最近 7 天自动对比，绿色表示进步、红色表示退步。
素材留痕反馈可附照片和短视频，家长端直接查看，删除反馈时一并清理。
管理视角按年级、班级查看整体情况，标出需关注学生，可导出报表。
家长周报老师周总评 + 量化小结 + 反馈明细，可打印或另存为 PDF。
零成本演示纯前端实现，无需后端即可完整演示产品流程。

演示步骤

先在同一个浏览器里打开「老师端演示」，添加学生或使用内置演示数据，录入一条带评分、带照片的反馈。
再打开「家长端演示」，切换到对应孩子，就能看到老师刚录入的反馈与素材。
在家长端点「本周报告」，查看老师周总评与进退步对比，并一键生成可打印的报告。
说明：这是用于作品展示的演示版，数据保存在当前浏览器本地，换设备或清理浏览器数据会重置。演示数据均为虚构，不含真实学生信息。
